# bilitube

bilitube is a small command-line tool I wrote for my own use. It publishes the
programming screencasts on [my YouTube channel](https://www.youtube.com/@richardvdoost):
it uploads a finished video, sets its title, description, chapters, tags and
thumbnail, and adds subtitle tracks in English, Chinese, Spanish and Russian.

It runs on my own computer, signs in to my own Google account, and only ever
touches my own channel. It is not a service, it has no other users, and it is
not offered to anyone else.
